The Pace for an actor is shown on the main tab of the character sheet, under 'Derived Stats'.

The _Savage Worlds Adventure Edition_ system allows Pace to be configured for four types of movement for an actor:
- **Ground** (defaults to 6 for new actors)
- **Fly**
- **Swim**
- **Burrow**

The Pace an actor uses by default (known as the base Pace type) can be set for each actor.

To view all of an actor's configured Paces, their base Pace type and a summary of how long they can run for outside of combat, hover your mouse over the 'Pace' box.

![Pace](systems/swade/assets/docs/pace-tooltip.png)

### Running Die

The Running die defaults to a d6 but can be overridden for each actor. This die is shared across all Pace types; having different Running dice for different movement modes is not currently supported.

To roll the Running die for a Player Character, click the die symbol next to the 'Pace' box. To roll for a Non-Player Character, click the heading of the 'Pace' box.

If the actor has more than one Pace type, a dialog will be presented to choose a type.

![Running Dialog](systems/swade/assets/docs/pace-running-dialog.png)

### Configuring Pace

Pace can be configured via the Tweaks dialog accessed from the title bar of the character sheet; scroll down to the end to view the settings. Make sure to click the 'Save Changes' button before closing the dialog.

![Configuring Pace](systems/swade/assets/docs/pace-tweaks.png)

### Choosing a Pace

To switch to a different Pace type (e.g. to change from Walking to Flying), right-click the actor's token in the scene and choose the 'walking man' icon. Note that this menu will show _all_ movement types, not just ones configured for the actor.

![Choosing a Pace](systems/swade/assets/docs/pace-choosing.png)

### Reducing Pace with Wounds

By default, the system will reduce an actor's pace when they receive wounds. If you wish to disable this, it can be found in the SWADE Setting Configurator.

![Reducing Pace with Wounds](systems/swade/assets/docs/pace-wounds.png)
